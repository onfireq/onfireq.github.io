linux:操作系统内核

内核做的事情：管理我们的硬件、提供系统调用、管理进程、管理内存、管理文件系统等。

我们是没办法使用内核的，我们只能使用内核提供的系统调用。
系统调用：内核提供的接口，我们可以通过系统调用来调用内核的功能。一个面向用户的发行版。

linux在服务器的操作系统这个领域，占比最高。我们在服务器上安装的软件和我们在个人电脑安装的软件是不一样的。在服务器的软件，一般对linux比较友好。

linux是一个开源的操作系统，它的代码是公开的，我们可以查看、修改、分发它的代码。（MIT许可证）

ubuntu:linux的一个发行版。

```text
22端口：默认远程登陆服务器的端口。
```

Nginix:持续监听80端口，返回网页内容。
其他功能：负载均衡、反向代理、缓存等。

安装命令：

```bash
sudo apt update             #更新软件源
sudo apt install nginx      #安装nginx
sudo systemctl start nginx  #启动nginx
```

apt：ubuntu的包管理器。
sudo：超级用户权限。用root用户权限执行命令。
systemctl：管理服务的工具。
nginx：web服务器。
-y：自动确认安装。

```bash
/usr/bin            #可执行文件的目录
/etc/               #各软件的配置文件
/etc/nginx/         #nginx的配置文件目录
/var/www            #nginx的默认网站目录
/var/log/nginx      #nginx的日志目录

/etc/nginx/nginx.conf           #nginx的主配置文件
/etc/nginx/sites-enabled/       #nginx的站点配置文件目录（启用的站点配置文件）
/etc/nginx/sites-available/     #nginx的站点配置文件目录（可用的站点配置文件）
/etc/nginx/conf.d/              #nginx的其他配置文件目录
/var/www/html/                  #nginx的默认网站目录
```

我们在浏览器中看到的页面，本质上对应了服务器中的一个html文件。

在国内，所有域名到云服务器的解析，都要经过备案。

域名的解析从技术上是非常简单的。
备案：在域名注册商的控制台，提交域名的备案信息。
备案信息：域名的注册信息、域名的解析信息、域名的使用信息等。
备案的单位有两种：

1. 个人备案
2. 企业备案

如果是个人备案，就不能做经营类型的网站。

在sites-available目录下，每个站点都有一个配置文件。改了什么东西，在sites-enabled目录下对应的配置文件也会改变。

监听某一个端口，当这个端口的请求过来的时候，把它转发到某一个路径上面。让这个里面的html文件去给用户响应。
