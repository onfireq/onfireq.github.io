html：超文本标记语言。
结构、样式、行为。

- 结构：html的标签。
- 样式：css。
- 行为：js。

```html
<!DOCTYPE html>
<html lang="zh-CN">
    <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>Document</title>
        <style>
            h1{
                color: red;
            }
        </style>
    </head>
    <body>
        <h1>Hello World</h1>
    </body>
</html>
```

html是一种文件的格式，用于描述网页的结构和内容。

```text
<!DOCTYPE html>声明文档类型。
<html lang="zh-CN">声明文档的语言。
<head>声明文档的头部。
<body>声明文档的主体。
</html>声明文档的结束。
<div>容器标签。用于包裹其他标签。用于组织文档的结构。


大部分时候，标签是成对出现。
标签的嵌套：一个标签可以包含另一个标签。
标签的闭合：一个标签必须有对应的结束标签。
标签的属性：标签可以有属性，用于描述标签的特征。
标签的值：标签可以有值，用于描述标签的特征。
标签的注释：标签可以有注释，用于描述标签的特征。

head标签：声明文档的头部。内容是不会显示在浏览器中的。定义文档的元数据。字符集、视口、标题等。
meta标签：声明文档的元数据。
title标签：声明文档的标题。
body标签：声明文档的主体。页面的内容。
```

服务器一直在持续监听客户端的请求。
监听到客户端的请求后，会根据请求的路径，返回对应的资源。
资源：html文件、css文件、js文件、图片文件等。

监听到一个事件后，会根据事件的类型，执行对应的操作。
例如监听到按钮的点击事件，会触发changeText()函数。
changeText()函数会把id为msg的元素的文本改掉。
按钮（被监听的元素，被监听到了这个事件）->onclick(触发changeText()函数)->id="msg"（获取id为msg的元素。）->textContent（把文本改掉）->显示在浏览器中。

一个html文件有三层东西：

- 内容和结构：html。
- 样式和外观：css。
- 行为和交互：js。
