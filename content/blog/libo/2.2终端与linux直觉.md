
# 终端与linux直觉

另外一种和电脑交互的方式，就是通过终端。
终端是一个文本界面，用户可以在其中输入命令，然后电脑会执行这些命令并返回结果。

UI界面是一个图形界面界面，用户可以在其中点击按钮、输入文本等操作。

二者之间的区别在于，终端是一个文本界面，而UI界面是一个图形界面。

作用：
终端的作用是执行用户输入的命令，然后返回结果。
UI界面的作用是提供一个图形化的界面，用户可以在其中进行操作。

终端（terminal）、命令行界面（command line interface）、
shell（shell interface）、cli（command line interface）等

使用终端的优势：

1. 在很多操作上，终端比UI界面更方便。（创建一些复杂的文件结构）
2. 终端可以批量操作，而UI界面不能。
3. 终端可以自动执行操作，而UI界面不能。

有些事情只能在终端完成，比如操作远程服务器。
AI时代将命令和报错贴给大模型，它会更理解你的处境。
开发工具链（Git、npm、pip、docker等）几乎都在终端里运行。

在开发过程中，我们通常会使用这些工具来管理代码、安装依赖、运行应用等。
这些工具在终端中都有对应的命令，用户可以直接在终端中执行。
如果用户不熟悉终端，他们可能会觉得操作比较麻烦。
但是，一旦熟悉了终端，他们就会发现，终端是一个非常强大的工具。
它可以帮助用户快速、方便地完成开发任务。
在AI时代，终端的使用会更加普遍。

终端：
macos
目录（directory）
进入某个目录（cd）
退出某个目录（cd ..）
创建某个目录（mkdir）
删除某个目录（rmdir）
查看某个目录下的文件（ls）
查看某个文件的内容（cat）

根目录（/），系统层级最高，包含所有其他目录，一般不建议直接操作。
用户目录（/Users/用户名），包含用户的所有文件和目录。
用户家目录（~/），包含用户的所有个人文件和目录。
用户家目录下的.bashrc文件，包含了用户的bash配置信息。

常用命令：

```terminal
pwd（打印当前目录）--print working directory
cd（进入目录）--change directory
mkdir（创建目录）--create directory
rmdir（删除空目录）--remove directory(empty directory)
ls（列出目录下的文件）--list files in directory
ls -l（列出目录下的文件，包含详细信息）
--list files in directory with detailed information
ls -a（列出目录下的所有文件，包括隐藏文件）
--list all files in directory, including hidden files

cat（查看文件内容）--cat file content
rm（删除文件）--remove file
mv（移动文件）--move file
cp（复制文件）--copy file
touch（创建文件）--create file

clear（清除屏幕）--clear screen

cd ..（退出当前目录）--exit current directory
cd ~/（进入用户家目录）--enter user home directory
cd /（进入根目录）--enter root directory

./（当前目录）--current directory
../（上一级目录）--parent directory
../../（上两级目录）--grandparent directory
../../../（上三级目录）--greatparent directory
```

终端: 没有消息就是好消息。

```terminal
mkdir new_dir

cd new_dir
touch new_file.txt

touch new_dir/new_file.txt
```

都表示在new_dir目录下创建一个文件new_file.txt。

1. 确认当前位置：

    ```terminal
    pwd
    ```

2. 创建练习目录：

    ```terminal
    mkdir new_dir
    ```

3. 进入练习目录：

    ```terminal
    cd new_dir
    ```

4. 创建文件：

    ```terminal
    touch new_file.txt
    ```

5. 编辑文件：

    ```terminal
    nano new_file.txt
    ```

    nano 是一个文本编辑器，用户可以在其中输入文本。

6. 退出文件编辑器：

    ```terminal
    exit
    ```

    退出文件编辑器后，文件会自动保存。

7. 查看文件内容：

    ```terminal
    cat new_file.txt
    ```

8. 删除文件：

    ```terminal
    rm new_file.txt
    ```

vim 是一个终端里面的文本编辑器，用户可以在其中输入文本。

先按“i”键，进入插入模式。
输入文本后，按“Esc”键，退出插入模式。
退出插入模式后，按“:”键，进入命令模式：
    - 输入“q”键，退出 vim 编辑器。
    - 输入“w”键，保存文件。
    - 输入“wq”键，保存文件并退出 vim 编辑器。
    - 输入“q!”键，强制退出 vim 编辑器。

一进终端，先看自己在哪（pwd），确认自己的位置。每做一步，立刻用pwd、ls、cat观察结果。删除前多看一眼，先pwd确认路径，再ls确认目标。
