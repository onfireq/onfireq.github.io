它们都是为了解决 CDC（跨时钟域）问题，但适用的数据类型不同。

先记住核心原因：当信号在目标时钟边沿附近变化时，目标寄存器可能进入亚稳态。单bit只需要解决"0还是1"，多bit还要保证"所有bit属于同一份数据"。

## 1. 两级同步器：同步单bit电平

适合：enable, ready, locked 等状态标志。

```verilog
reg sync_d1;
reg sync_d2;

always @(posedge dst_clk or negedge rst_n) begin
    if (!rst_n) begin
        sync_d1 <= 1'b0;
        sync_d2 <= 1'b0;
    end else begin
        sync_d1 <= async_signal;
        sync_d2 <= sync_d1;
    end
end
```

但它不适合很窄的单拍脉冲。例如源时钟产生8 ns脉冲，目标时钟可能完全没有采到它。

## 2. Toggle同步：传递单次事件

适合：tx_start, 采样完成, 一次性触发事件。

### 源时钟域

每发生一次事件，把一个bit翻转：

```verilog
reg event_toggle;

always @(posedge src_clk or negedge rst_n) begin
    if (!rst_n)
        event_toggle <= 1'b0;
    else if (event_pulse)
        event_toggle <= ~event_toggle;
end
```

### 目标时钟域

先经过两级同步，然后比较当前值和上一拍：

```verilog
wire event_dst_pulse = toggle_sync2 ^ toggle_sync_d1;
```

### Toggle限制

两次事件不能靠得太近。事件间隔至少大于 2~3 个目标时钟周期。

你的 `tx_mark` 每100 μs发生一次，而时钟周期只有8 ns，所以非常适合 toggle 同步。

## 3. 为什么多bit不能每位单独两级同步

假设源域数据从 `0111` 变化到 `1000`，四个bit不是绝对同时到达同步寄存器。目标域可能短暂采到 `0000`、`1111`、`1010` 等不存在的中间值。

所以多bit数据必须保证：目标域采集时，整组数据保持不变。

## 4. 异步FIFO：连续传输多bit数据

适合：连续ADC采样流、高速数据流、源域和目标域频率不同。

```text
写时钟域                  读时钟域
adc1_clk                  clk_125m

ADC数据 → 写FIFO → 双口RAM → 读FIFO → 测量逻辑
```

优先使用 Xilinx 提供的 `xpm_fifo_async` 或 FIFO Generator IP。

**优点**：多bit数据不会撕裂
**缺点**：会引入固定延迟，影响精确的传播延时测量

## 5. 握手机制：偶尔传输一个多bit数据

适合：一次测量结果、配置字、32位时间戳、每隔很长时间才更新的数据。

握手使用两个单bit控制信号：req 和 ack。

```text
源域 data：   ====== 新数据一直保持 ======
源域 req ：   ____────────────___________
目标域 ack：  ______________________
```

源域在整个握手期间保持 data 不变。等 `req` 经过两级同步到目标域时，数据已经稳定了多个时钟周期，因此目标域可以整体锁存。

## 6. 数据保持稳定，再同步有效标志

这是握手的简化版。源域先锁存 data_hold，然后只把 valid_toggle 通过两级同步。

```text
data_hold[31:0] ─────────────────────→ 目标寄存器
                     数据一直稳定

valid_toggle ─→ 两级同步 ─→ 检测变化 ─→ 锁存data_hold
```

源域必须保证：目标域锁存完成以前，data_hold 绝对不能再次变化。

## 7. 直接使用数据所属的时钟

这是最简单、最可靠的思路：数据在哪个时钟域产生，就在那个时钟域完成主要处理。

ADC数据属于 `adc1_clk` 域，那么在 `adc1_clk` 域完成：采集、滤波、阈值计算、边沿检测、rx时间计数。

不要把每个ADC样点都送到 `clk_125m`。只跨域传输最终结果。

## 8. 该怎么选择

```text
单bit持续电平          → 两级同步器
单次脉冲/事件          → Toggle同步
偶尔更新多bit结果      → 握手，或data_hold+valid_toggle
连续多bit数据流        → 异步FIFO
能在源时钟域完成处理   → 直接使用源时钟，最后只跨域传结果
```

对应你的工程：

```text
tx_mark          → toggle同步到adc1_clk
ADC连续采样数据    → 留在adc1_clk域处理
loop_delay_ns    → data_hold + valid_toggle传回clk_125m
VIO配置参数      → 在测量开始时锁存，或使用握手更新
```

需要注意的是，`tx_mark` 经过两级同步进入 `adc1_clk` 后，会增加约2~3个 `adc1_clk` 周期，并存在约一拍的相位不确定性。125 MHz下就是约16~24 ns固定延迟、约8 ns量化不确定性。如果只要求几十纳秒级精度，可以标定并扣除；如果要求更高精度，就需要做时钟相位测量。
